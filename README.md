## Sobre o projeto

Site estático feito com HTML, CSS e JavaScript puros, sem frameworks ou etapas de build. Ele é publicado com GitHub Pages, e cada `git push` na branch `main` atualiza a página.

## Como executar localmente

Não é preciso instalar nada. Basta abrir o arquivo `index.html` no navegador ou, de preferência, usar uma extensão como o Live Server no VS Code.

```bash
git clone https://github.com/JaldsonArthur17/jaldsonarthur17.github.io.git
cd jaldsonarthur17.github.io
```

## Publicação

1. No GitHub, vá em **Settings > Pages**.
2. Em **Source**, escolha **Deploy from a branch**.
3. Selecione a branch `main` e a pasta `/ (root)`.
4. Salve e aguarde alguns minutos.
